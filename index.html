workspace-cli

A private command-line tool for synchronizing the owner's research state files between a personal computer/server and Google Drive using rclone.

Google Drive access

The tool uses Google OAuth authorization to list and download files from configured Drive folders and upload local research state files to a configured output folder. The configured OAuth scope permits broad Drive access; the synchronization workflow uses selected folders.

This tool is for the owner's personal use and is not a public service. This website contains only app information; it does not host research data or authentication credentials.
